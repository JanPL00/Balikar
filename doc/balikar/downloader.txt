downloader
=============
(English below)

Popis
----
Zdrojový soubor: src/balikar/downloader.c
Hlavičkový soubor: src/balikar/includes/downloader.h

Modul downloader zajišťuje stahování balíkových archivů (tar.bz2 z balikar
repozitáře) a zdrojových archivů (tar.gz/tar.xz z upstream serverů) přes
libcurl. Pro každý balík se nejprve stáhne repository tar.bz2 obsahující
metadata + extras (patche, build.sh), z něj se získá URL skutečného
zdrojového archivu, ten se stáhne a předá do builderu jako otevřený FILE*.

Workflow funkce download_package():
    1. Sestavení cílové cesty v lokální cache (/var/cache/balikar/downloads
       nebo ~/.cache/balikar/downloads pro user instalaci)
    2. Pokud archiv již existuje a má nenulovou velikost: znovupoužití
    3. Jinak stažení přes CURL z URL získaného z metadat (loc parametr)
    4. Pokud byl předán source_array: pokus o extrakci embedded zdrojového
       archivu z repository tar.bz2 (extract_and_check_embedded_source) –
       umožňuje fallback pro mirrors, které již zmizely
    5. Postupný pokus o stažení každého URL ze source_array (mirror list)
    6. Otevření výsledného souboru a vrácení FILE* volajícímu

Modul implementuje progress bar (progress_callback) zobrazující procenta
a velikost v MB. Pro libcurl jsou nastaveny hooks write_data
(writer do FILE*) a progress_callback (UI feedback).

Druhý vstupní bod download_package_to_directory() ukládá archiv do
uživatelem zvoleného adresáře (--output-dir) a používá ho příkaz
balikar download.


Klíčové funkce
----

FILE *download_package(Solvable *s, const char *loc, Pool *pool,
                       json_t *source_array, const char *repo_path);
- Hlavní stahovací funkce. Vrací otevřený FILE* na hotový archiv,
  připravený pro builder.commit_element(). Caller musí soubor zavřít.
- Implementuje cache (znovupoužití), fallback přes mirror list a
  embedded source extraction.
- Vrací NULL při selhání všech zdrojů.

int download_package_to_directory(Solvable *s, const char *loc,
                                  Pool *pool, json_t *source_array,
                                  const char *output_dir, ...);
- Varianta pro příkaz balikar download. Uloží archiv do output_dir
  místo cache. Zachovává původní jméno souboru.
- Vrací 0 při úspěchu, ERR_DOWNLOAD_FAIL při selhání.

void download_extras(json_t *extras, const char *pkg_name,
                     const char *version, const char *repo_base_url,
                     const char *tmp_dir);
- Stáhne extras (patche, dodatečné build skripty) z extras/ podadresáře
  repozitáře do dočasného build adresáře. Volá se před commit_element().

int download_url_to_file(const char *url, const char *output_path);
- Nízkoúrovňová pomocná funkce: stažení libovolného URL do souboru.
  Použito pro repodata.json fetch z parser.c.

static int extract_and_check_embedded_source(...);
- Pokud je v balikar tar.bz2 vložený zdrojový tarball (např. když
  byl source URL nedostupný v době přípravy), rozbalí ho a předá dál.

static size_t write_data(...);
static int progress_callback(...);
- libcurl hooks pro zápis dat a UI progress.


Chybové kódy
----
NULL                Vrácen z download_package() při selhání všech zdrojů
ERR_DOWNLOAD_FAIL   Síťové chyby (timeout, HTTP 404), selhání cache write
                    Návratový kód CURL různý od CURLE_OK


Integrace v projektu
----
Volán z cmd_install_or_build_execute() (viz cmd_install.txt) přes
ctx->subsystems.download_package a download_extras. URL zdrojů
získává parser.c (get_custom_source, get_custom_source_array,
get_custom_extras). Cache adresář je nakonfigurován v common.h
(DOWNLOAD_DIR / per-user equivalent). Použit také příkazem balikar
download (cmd_download.c) pro samostatné stahování bez instalace.

downloader
=============

Description
----
Source file: src/balikar/downloader.c
Header: src/balikar/includes/downloader.h

The downloader module fetches both package archives (tar.bz2 from the
balikar repository) and upstream source archives (tar.gz/tar.xz) via
libcurl. For each package it first downloads the repository tar.bz2
holding metadata + extras (patches, build.sh), extracts the URL of the
actual source archive, downloads it, and hands the open FILE* to the
builder.

download_package() workflow:
    1. Build target path in the local cache
       (/var/cache/balikar/downloads or ~/.cache/balikar/downloads for
       user installs)
    2. If the archive already exists with non-zero size: reuse it
    3. Otherwise download via CURL from the URL stored in metadata (loc)
    4. If source_array was supplied: attempt to extract an embedded
       source archive from the repo tar.bz2
       (extract_and_check_embedded_source) – fallback for vanished
       upstream mirrors
    5. Try each URL in source_array sequentially (mirror list)
    6. Open the resulting file and return the FILE* to the caller

The module implements a progress bar (progress_callback) displaying
percentage and size in MB. libcurl hooks are write_data (writer to
FILE*) and progress_callback (UI feedback).

Second entry point download_package_to_directory() stores the archive
in a user-chosen directory (--output-dir) and is used by the
balikar download command.


Key functions
----

FILE *download_package(Solvable *s, const char *loc, Pool *pool,
                       json_t *source_array, const char *repo_path);
- Main download function. Returns an open FILE* on the finished
  archive ready for builder.commit_element(). Caller must close it.
- Implements caching, mirror-list fallback and embedded source
  extraction.
- Returns NULL if every source fails.

int download_package_to_directory(Solvable *s, const char *loc,
                                  Pool *pool, json_t *source_array,
                                  const char *output_dir, ...);
- Variant for the balikar download command. Stores the archive in
  output_dir instead of the cache. Keeps the original file name.
- Returns 0 on success, ERR_DOWNLOAD_FAIL on failure.

void download_extras(json_t *extras, const char *pkg_name,
                     const char *version, const char *repo_base_url,
                     const char *tmp_dir);
- Fetches extras (patches, extra build scripts) from the extras/
  subdirectory of the repository into the temporary build dir.
  Called before commit_element().

int download_url_to_file(const char *url, const char *output_path);
- Low-level helper: download an arbitrary URL into a file. Used by
  parser.c for repodata.json fetching.

static int extract_and_check_embedded_source(...);
- When the balikar tar.bz2 contains an embedded source tarball (e.g.,
  the original source URL was unavailable at packaging time), unpack
  it and forward.

static size_t write_data(...);
static int progress_callback(...);
- libcurl hooks for data write and UI progress.


Error codes
----
NULL                Returned by download_package() when every source
                    fails
ERR_DOWNLOAD_FAIL   Network errors (timeout, HTTP 404), cache write
                    failure, CURL return value other than CURLE_OK


Project integration
----
Called from cmd_install_or_build_execute() (see cmd_install.txt) via
ctx->subsystems.download_package and download_extras. Source URLs are
provided by parser.c (get_custom_source, get_custom_source_array,
get_custom_extras). The cache directory is configured in common.h
(DOWNLOAD_DIR / per-user equivalent). Also used by the balikar download
command (cmd_download.c) for stand-alone fetches without installation.
