downloader
=============
(English below)

Popis
----
Zdrojový soubor: downloader.c

Tento modul poskytuje funkce pro stahování balíčků (lokální copy nebo remote HTTP/HTTPS pomocí libcurl),
cachování stažených balíčků, a stahování extras (patche/skripty).
Integruje se s parser.c (get_custom_source, get_custom_extras) a používá Repodata pro získání source[] pole.
Podporuje multi-source fallback pro vysokou dostupnost balíčků.

Klíčové funkce
----
static size_t write_data(void *ptr, size_t size, size_t nmemb, void *stream);
- Callback funkce pro libcurl; zapisuje stažená data do FILE stream pomocí fwrite;
  vrací počet zapsaných bytů; používá se v curl_easy_setopt(CURLOPT_WRITEFUNCTION).

static int progress_callback(void *clientp, curl_off_t dltotal, curl_off_t dlnow, curl_off_t ultotal, curl_off_t ulnow);
- Progress callback pro libcurl; zobrazuje progress bar během stahování;
  formát: [=====>     ] 45% (5.2MB/11.5MB);
  používá stderr pro output aby neinterferoval s logováním;
  automaticky přejde na nový řádek po dokončení (dlnow >= dltotal);
  vrací 0 pro pokračování, nenulovou hodnotu pro abort;
  používá se v curl_easy_setopt(CURLOPT_XFERINFOFUNCTION).



FILE *download_package(Solvable *s, const char *loc, Pool *pool, Repodata *data, const char *repo_path);
- Hlavní funkce pro stažení balíčku: Alokuje cache_dir (CACHE_DIR macro -> get_cache_dir inline funkce),
  načte source[] pole z metadat (get_custom_source_array), vytvoří cache path ("<cache_dir>/<name>-<version><ext>"),
  zkontroluje cache existence (access) -> pokud OK, vrátí fopen(cache_path, "r");
  MULTI-SOURCE FALLBACK: iteruje přes všechny URL v source[] poli:
    - Pro každou URL (source[i].url) zkusí stáhnout/zkopírovat
    - Detekuje lokální vs remote (lokální = cesta nezačíná "http://", "https://", "ftp://", "file://")
    - LOKÁLNÍ: cp příkazem kopíruje do cache, při úspěchu nastaví download_success=1
    - REMOTE: fopen(cache_path, "wb"), inicializuje CURL (curl_easy_init), nastaví URL/WRITEFUNCTION/WRITEDATA/FOLLOWLOCATION/FAILONERROR,
      stáhne (curl_easy_perform), při úspěchu nastaví download_success=1, při chybě odstraní částečný download (remove)
    - Pokud stažení z aktuální URL selže, automaticky zkusí další URL v poli (log_warn)
    - Ukončí se při prvním úspěšném stažení
  LOKÁLNÍ FALLBACK: pokud všechny source[] URL selžou, zkusí lokální strukturu repozitáře:
    "<repo_path>/<first_char>/<name>/<name>-<version>.tar.bz2"
  cleanup: free(cache_dir); vrací fopen(cache_path, "rb") pro builder nebo NULL pokud všechny zdroje selhaly (log_error).
  
NOVÉ: Automatický fallback na další URL při selhání stahování zajišťuje vysokou dostupnost balíčků.

void download_extras(json_t *extras, const char *pkg_name, const char *tmp_dir);
- Stáhne extra soubory (patche) z JSON array extras (pole URL stringů);
  vytvoří extras_subdir ("<CACHE_DIR>/extras/<pkg_name>"), pro každý extra URL:
  extrahuje extra_name (basename z URL), vytvoří extra_path, zkontroluje cache (access), pokud cached: skip,
  jinak: fopen(extra_path, "wb"), inicializuje CURL, stáhne (curl_easy_perform), loguje úspěch/chybu;
  žádná verifikace hash (extras nemají metadata SHA); používá se v builderu pro aplikaci patchů před buildem;
  parameter tmp_dir je nepoužitý (legacy, mohlo by se odstranit).

Integrace v projektu
----
Používá se v builderu (build.c): po solve_dependencies, pro každý Solvable v transaction:
načte download_url (get_custom_source z parser.c), volá download_package(s, url, pool, data),
získá FILE* s tar.bz2 obsahem (v cache), extrahuje do build dir, aplikuje extras (download_extras),
spustí build skript. Cache ("/var/cache/balikar/downloads/") přetrvává mezi buildy, SHA sidecar soubory
umožňují verify i bez metadata v repo. Testováno v test_downloader.c (Check framework) s mock soubory;
~80% coverage včetně local/remote, SHA match/mismatch, cache reuse.

Poznámky
----
- CACHE_DIR macro: Expanze pomocí inline get_cache_dir() funkce (alokuje buffer, caller free);
  výchozí cesta je pevně "/var/cache/balikar/downloads/".
- Dočasné session adresáře (tmp_session_*) se již nevytvářejí; stahování probíhá přímo do finální cache cesty.
- Detekce přípony archivu pro název v cache zachovává vícenásobné přípony: podporováno .tar.xz, .tar.gz, .tar.bz2 i .tgz.
- Multi-source fallback zvyšuje robustnost systému při výpadcích mirror serverů.

downloader
=============

Description
----
Source file: downloader.c

This module provides functions for downloading packages (local copy or remote HTTP/HTTPS using libcurl),
caching of downloaded packages, and downloading extras (patches/scripts).
Integrates with parser.c (get_custom_source, get_custom_extras) and uses Repodata to retrieve source[] array.
Supports multi-source fallback for high package availability.

Key functions
----
static size_t write_data(void *ptr, size_t size, size_t nmemb, void *stream);
- Callback function for libcurl; writes downloaded data to FILE stream using fwrite;
  returns number of bytes written; used in curl_easy_setopt(CURLOPT_WRITEFUNCTION).

static int progress_callback(void *clientp, curl_off_t dltotal, curl_off_t dlnow, curl_off_t ultotal, curl_off_t ulnow);
- Progress callback for libcurl; displays progress bar during download;
  format: [=====>     ] 45% (5.2MB/11.5MB);
  uses stderr for output to not interfere with logging;
  automatically adds newline after completion (dlnow >= dltotal);
  returns 0 to continue, non-zero to abort;
  used in curl_easy_setopt(CURLOPT_XFERINFOFUNCTION).



FILE *download_package(Solvable *s, const char *loc, Pool *pool, Repodata *data, const char *repo_path);
- Main function for package download: Allocates cache_dir (CACHE_DIR macro -> get_cache_dir inline function),
  loads source[] array from metadata (get_custom_source_array), creates cache path ("<cache_dir>/<name>-<version><ext>"),
  checks cache existence (access) -> if OK, returns fopen(cache_path, "r");
  MULTI-SOURCE FALLBACK: iterates through all URLs in source[] array:
    - For each URL (source[i].url) attempts to download/copy
    - Detects local vs remote (local = path does not start with "http://", "https://", "ftp://", "file://")
    - LOCAL: copies to cache using cp command, on success sets download_success=1
    - REMOTE: fopen(cache_path, "wb"), initializes CURL (curl_easy_init), sets URL/WRITEFUNCTION/WRITEDATA/FOLLOWLOCATION/FAILONERROR,
      downloads (curl_easy_perform), on success sets download_success=1, on failure removes partial download (remove)
    - If download from current URL fails, automatically tries next URL in array (log_warn)
    - Stops at first successful download
  LOCAL FALLBACK: if all source[] URLs fail, tries local repository structure:
    "<repo_path>/<first_char>/<name>/<name>-<version>.tar.bz2"
  cleanup: free(cache_dir); returns fopen(cache_path, "rb") for builder or NULL if all sources failed (log_error).
  
NEW: Automatic fallback to next URL on download failure ensures high package availability.

void download_extras(json_t *extras, const char *pkg_name, const char *tmp_dir);
- Downloads extra files (patches) from JSON array extras (array of URL strings);
  creates extras_subdir ("<CACHE_DIR>/extras/<pkg_name>"), for each extra URL:
  extracts extra_name (basename from URL), creates extra_path, checks cache (access), if cached: skip,
  otherwise: fopen(extra_path, "wb"), initializes CURL, downloads (curl_easy_perform), logs success/error;
  no hash verification (extras have no metadata SHA); used in builder for applying patches before build;
  parameter tmp_dir is unused (legacy, could be removed).

Project integration
----
Used in builder (build.c): after solve_dependencies, for each Solvable in transaction:
loads download_url (get_custom_source from parser.c), calls download_package(s, url, pool, data),
gets FILE* with tar.bz2 content (in cache), extracts to build dir, applies extras (download_extras),
runs build script. Cache ("/var/cache/balikar/downloads/") persists between builds, SHA sidecar files
allow verify even without metadata in repo. Tested in test_downloader.c (Check framework) with mock files;
~80% coverage including local/remote, SHA match/mismatch, cache reuse.

Notes
----
- CACHE_DIR macro: Expands via inline get_cache_dir() function (allocates buffer, caller free);
  default path is fixed to "/var/cache/balikar/downloads/".
- Temporary session directories (tmp_session_*) are no longer created; downloads are written directly to the final cache path.
- Archive extension detection for cache naming preserves multi-dot extensions: recognized .tar.xz, .tar.gz, .tar.bz2 and .tgz.
- Multi-source fallback increases system robustness during mirror server outages.
