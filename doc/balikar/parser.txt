parser
=============
(English below)

Popis
----
Zdrojový soubor: parser.c

Tento modul poskytuje funkce pro parsování repozitáře balíčků v Conda-like formátu (index.json pro každý balíček),
rekurzivní procházení adresářové struktury, generování repodata.json a integraci metadat do libsolv struktur (Solvables a Repodata).
Podporuje custom pole inspirovaná LFS/LLD (mkdeps pro build-time závislosti, source pro URL stažení, extras pro patche/skripty,
is_group/no_package pro meta/virtual balíčky).
Zahrnuje parsování závislostí (depends array do SOLVABLE_REQUIRES) a error handling s loggingem.
Rozšířeno o podporu tar.bz2 balíčků (extrakce, rekurzní hledání index.json, generování default metadat pokud chybí),
což umožňuje parsování mixu adresářů a archivů v repo i lokálně mimo repo.




Klíčové funkce
----

static char* trim_str(const char* str);
- Ořízne leading/trailing whitespace z stringu; vrací nový mallocovaný string nebo NULL.

json_t* load_json(const char* filepath);
- Načte JSON soubor (např. index.json) pomocí jansson; vrací root objekt nebo NULL při chybě (s log_error).

static json_t* find_and_load_index(const char* dir_path);
- Rekurzivně hledá a načte první index.json v adresáři (podporuje root/info/ a podadresáře); vrací JSON nebo NULL; použito pro tar.bz2 extrakty.

static void add_default_fields(json_t* index);
- Doplněuje defaultní pole do index JSON (build_number=0, license="unknown", md5="", size=0, subdir="noarch", timestamp=aktuální).

static Id init_solvable_from_json(json_t *index, Pool *pool, Repo *repo);
- Inicializuje Solvable z JSON (nastaví name, evr z version+build, arch s fallbackem na get_pool_arch, parsuje depends); vrací Id Solvable nebo 0.

static void add_custom_fields_to_repodata(json_t *index, Repodata *data, Id p, Pool *pool);
- Přidává custom pole (mkdeps, download_url, extras, is_group, no_package) do Repodata jako stringy (json_dumps pro array).

static json_t* generate_default_metadata(const char* filename);
- Generuje default JSON metadata z filename (sscanf name-version-build, depends/mkdeps/extras=[], is_group/no_package=false, source=""); vrací JSON nebo NULL.

static Id process_index_json(json_t *index, json_t *packages, Pool *pool, Repo repo, const char fallback_source);
- Obecný processor JSON: Doplňuje defaulty, inicializuje Solvable, přidává custom do Repodata, volitelně přidá do packages (pro repodata.json), nastaví fallback source pokud chybí; vrací Id Solvable.

char* generate_package_key(json_t* index);
- Generuje unikátní klíč balíčku ("name-version-build.tar.bz2") z polí name/version/build; vrací mallocovaný string nebo NULL.

void collect_packages(const char* root_path, json_t* packages, Pool *pool, Repo *repo);
- Rekurzivně prochází adresář repo, načítá index.json (pro plain adresáře), nebo volá add_package_tar_bz2 pro tar.bz2 soubory (DT_REG a končí .tar.bz2); doplňuje defaultní pole, vytváří Solvables (s name/EVR/arch), ukládá custom metadata do Repodata (mkdeps/source/extras/is_group/no_package) a parsuje depends; přidává do packages objektu pro repodata.json.

int generate_repodata(const char* repo_path, Pool *pool, Repo *repo);
- Hlavní entry point: Vytváří repodata.json (s info/packages sekcemi), volá collect_packages (nyní s tar.bz2 podporou) a zapisuje výstup; volitelně integruje s libsolv (pool/repo); vrací 0 při úspěchu.

static int check_index_newer_than_repodata(const char *repo_path, time_t repodata_mtime);
- Rekurzivně kontroluje, zda je nějaký index.json soubor novější než repodata.json (podle modification time).
  Prochází adresářovou strukturu repo, testuje index.json a info/index.json soubory.
  Vrací 1 pokud najde novější soubor, jinak 0. Používá se pro automatickou detekci změn v metadatech.

Repo *load_repository(Pool *pool, const char *repo_path);
- Načítá repository do libsolv struktury: Nastaví system arch (set_system_arch), kontroluje existenci a aktuálnost repodata.json
  (pomocí check_index_newer_than_repodata), automaticky regeneruje repodata.json pokud chybí nebo pokud jsou některé index.json
  soubory novější (detekce změn podle mtime), volá repo_add_conda (načte standardní conda pole), poté znovu načítá JSON a manuálně 
  injektuje custom pole (download_url, mkdeps, extras, is_group, no_package) pomocí repodata_set_str (repo_add_conda ignoruje 
  custom pole). Opravuje arch na "noarch" pro solvables s neplatnou arch (0 nebo 1).
  Finalizuje repo_internalize, nastavuje self-provides pro všechny solvables, volá pool_createwhatprovides; vrací Repo* nebo NULL při chybě.
  
POZNÁMKA: Automatická detekce změn znamená, že úpravy v index.json se projeví při příštím načtení repository (např. balikar repos, 
balikar install). Pro force regeneraci bez ohledu na timestampy použij balikar repo-update příkaz.

void parse_depends_to_solvable(Solvable *s, json_t *depends, Pool *pool);
- Parsuje depends array (stringy jako "pkg >= 1.0") do Reldep Id (pool_rel2id s REL_* konstantami) a přidává do s->requires (solvable_add_deparray); skipuje invalidní položky; používá trim_str pro ořez stringů.

json_t* get_custom_mkdeps(Repodata *data, Id p, Pool *pool);
- Lookup "makedeps" string z Repodata, parsuje zpět do json_array (json_loads); vrací array (caller json_decref) nebo NULL.

const char* get_custom_source(Repodata *data, Id p, Pool *pool);
- Lookup "download_url" string z Repodata; vrací URL nebo local path nebo NULL (bez free). Hodnota může být remote URL (http/https/ftp) nebo local path (relativní nebo absolutní cesta k balíčku).

json_t* get_custom_extras(Repodata *data, Id p, Pool *pool);
- Lookup "extras" string z Repodata, parsuje do json_array; vrací array (caller json_decref) nebo NULL.

int get_custom_is_group(Repodata *data, Id p, Pool *pool);
- Lookup "is_group" string ("true"/"false") z Repodata; vrací bool (1/0).

int get_custom_no_package(Repodata *data, Id p, Pool *pool);
- Lookup "no_package" string ("true"/"false") z Repodata; vrací bool (1/0).

void internalize_repo(Repo *repo);
- Volá repo_internalize pro indexaci repo (whatprovides/obsoletes); loguje info.

Id add_package_tar_bz2(const char *tar_path, Pool *pool, Repo *repo);
- Přidává tar.bz2 balíček do Repo: Extrahuje do tmp (tar xjf), rekurzivně hledá index.json (find_and_load_index),
  generuje default pokud chybí (generate_default_metadata),
  zpracovává JSON (process_index_json s fallback_source=tar_path), finalizuje (repo_internalize, pool_createwhatprovides); vrací Id Solvable nebo 0 při chybě; cleanup tmp.

Integrace v projektu
----
Používá se v main.c pro inicializaci repo (generate_repodata("/tmp/test_repo", pool, repo)) a v solver.c pro načtení metadat
(get_custom_* pro mkdeps rekurzi, parse_depends_to_solvable).
Podpora tar.bz2 umožňuje mix adresářů a archivů v repo (collect_packages volá add_package_tar_bz2 pro .tar.bz2 soubory)
i lokálně mimo repo (přímé volání add_package_tar_bz2).
Testováno v test_parser.c (Check framework) s /tmp/test_repo; ~80% coverage pro core funkce, včetně tar.bz2 scénářů.

parser

Description
----
Source file: parser.c

This module provides functions for parsing a package repository in Conda-like format (index.json per package),
recursive directory traversal, generating repodata.json, and integrating metadata into libsolv structures (Solvables and Repodata).
It supports custom fields inspired by LFS/LLD (mkdeps for build-time dependencies, source for download URL, extras for patches/scripts,
is_group/no_package for meta/virtual packages).
Includes dependency parsing (depends array to SOLVABLE_REQUIRES) and error handling with logging.
Extended to support tar.bz2 packages (extraction, recursive index.json search, default metadata generation if missing),
allowing parsing of mixed directories and archives in repo or locally outside repo.



Key functions
----

static char* trim_str(const char* str);
- Trims leading/trailing whitespace from string; returns new malloc'd string or NULL.

json_t* load_json(const char* filepath);
- Loads JSON file (e.g., index.json) using jansson; returns root object or NULL on error (with log_error).

static json_t* find_and_load_index(const char* dir_path);
- Recursively searches and loads the first index.json in directory (supports root/info/ and subdirs); returns JSON or NULL; used for tar.bz2 extracts.

static void add_default_fields(json_t* index);
- Adds default fields to index JSON (build_number=0, license="unknown", md5="", size=0, subdir="noarch", timestamp=current).

static Id init_solvable_from_json(json_t *index, Pool *pool, Repo *repo);
- Initializes Solvable from JSON (sets name, evr from version+build, arch with fallback to get_pool_arch, parses depends); returns Solvable Id or 0.

static void add_custom_fields_to_repodata(json_t *index, Repodata *data, Id p, Pool *pool);
- Adds custom fields (mkdeps, download_url, extras, is_group, no_package) to Repodata as strings (json_dumps for arrays).

static json_t* generate_default_metadata(const char* filename);
- Generates default JSON metadata from filename (sscanf name-version-build, depends/mkdeps/extras=[], is_group/no_package=false, source=""); returns JSON or NULL.

static Id process_index_json(json_t *index, json_t *packages, Pool *pool, Repo repo, const char fallback_source);
- Generic JSON processor: Adds defaults, initializes Solvable, adds custom to Repodata, optionally adds to packages (for repodata.json), sets fallback source if missing; returns Solvable Id.

char* generate_package_key(json_t* index);
- Generates unique package key ("name-version-build.tar.bz2") from name/version/build fields; returns malloc'd string or NULL.

void collect_packages(const char* root_path, json_t* packages, Pool *pool, Repo *repo);
- Recursively traverses repo directory, loads index.json (for plain directories), or calls add_package_tar_bz2 for tar.bz2 files (DT_REG ending .tar.bz2); adds default fields, creates Solvables (with name/EVR/arch), stores custom metadata in Repodata (mkdeps/source/extras/is_group/no_package), and parses depends; adds to packages object for repodata.json.

int generate_repodata(const char* repo_path, Pool *pool, Repo *repo);
- Main entry point: Creates repodata.json (with info/packages sections), calls collect_packages (now with tar.bz2 support), and writes output; optionally integrates with libsolv (pool/repo); returns 0 on success.

static int check_index_newer_than_repodata(const char *repo_path, time_t repodata_mtime);
- Recursively checks if any index.json file is newer than repodata.json (based on modification time).
  Traverses repo directory structure, testing index.json and info/index.json files.
  Returns 1 if newer file found, otherwise 0. Used for automatic change detection in metadata.

Repo *load_repository(Pool *pool, const char *repo_path);
- Loads repository into libsolv structure: Sets system arch (set_system_arch), checks existence and freshness of repodata.json
  (using check_index_newer_than_repodata), automatically regenerates repodata.json if missing or if any index.json files are newer
  (change detection based on mtime), calls repo_add_conda (loads standard conda fields), then re-loads JSON and manually injects 
  custom fields (download_url, mkdeps, extras, is_group, no_package) via repodata_set_str (repo_add_conda ignores custom fields). 
  Fixes arch to "noarch" for solvables with invalid arch (0 or 1).
  Finalizes with repo_internalize, sets self-provides for all solvables, calls pool_createwhatprovides; returns Repo* or NULL on error.
  
NOTE: Automatic change detection means that edits to index.json files will take effect on next repository load (e.g., balikar repos,
balikar install). For force regeneration regardless of timestamps, use balikar repo-update command.

void parse_depends_to_solvable(Solvable *s, json_t *depends, Pool *pool);
- Parses depends array (strings like "pkg >= 1.0") into Reldep Id (pool_rel2id with REL_* constants) and adds to s->requires (solvable_add_deparray); skips invalid items; uses trim_str for string trimming.

json_t* get_custom_mkdeps(Repodata *data, Id p, Pool *pool);
- Looks up "makedeps" string from Repodata, parses back to json_array (json_loads); returns array (caller json_decref) or NULL.

const char* get_custom_source(Repodata *data, Id p, Pool *pool);
- Looks up "download_url" string from Repodata; returns URL or local path or NULL (no free). Value can be a remote URL (http/https/ftp) or local path (relative or absolute path to package).

json_t* get_custom_extras(Repodata *data, Id p, Pool *pool);
- Looks up "extras" string from Repodata, parses to json_array; returns array (caller json_decref) or NULL.

int get_custom_is_group(Repodata *data, Id p, Pool *pool);
- Looks up "is_group" string ("true"/"false") from Repodata; returns bool (1/0).

int get_custom_no_package(Repodata *data, Id p, Pool *pool);
- Looks up "no_package" string ("true"/"false") from Repodata; returns bool (1/0).

void internalize_repo(Repo *repo);
- Calls repo_internalize to index repo (whatprovides/obsoletes); logs info.

Id add_package_tar_bz2(const char *tar_path, Pool *pool, Repo *repo);
- Adds tar.bz2 package to Repo: Extracts to tmp (tar xjf), recursively searches for index.json (find_and_load_index),
generates default if missing (generate_default_metadata),
processes JSON (process_index_json with fallback_source=tar_path), finalizes (repo_internalize, pool_createwhatprovides); returns Id Solvable or 0 on error; cleanup tmp.

Project integration
----
Used in main.c for repo initialization (generate_repodata("/tmp/test_repo", pool, repo)) and in solver.c for metadata loading
(get_custom_* for mkdeps recursion, parse_depends_to_solvable). tar.bz2 support allows mixing directories and archives in repo
(collect_packages calls add_package_tar_bz2 for .tar.bz2 files) and locally outside repo (direct call to add_package_tar_bz2).
Tested in test_parser.c (Check framework) with /tmp/test_repo; ~80% coverage for core functions, including tar.bz2 scenarios.
