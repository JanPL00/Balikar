parser

(English below)

Popis
----
Zdrojový soubor: parser.c

Tento modul poskytuje funkce pro parsování repozitáře balíčků v Conda-like formátu (index.json pro každý balíček), rekurzivní procházení adresářové struktury, generování repodata.json a integraci metadat do libsolv struktur (Solvables a Repodata). Podporuje custom pole inspirovaná LFS/LLD (mkdeps pro build-time závislosti, source pro URL stažení, extras pro patche/skripty, is_group/no_package pro meta/virtual balíčky). Zahrnuje parsování závislostí (depends array do SOLVABLE_REQUIRES) a error handling s loggingem.

Klíčové funkce
----
json_t* load_json(const char* filepath);
    - Načte JSON soubor (např. index.json) pomocí jansson; vrací root objekt nebo NULL při chybě (s log_error).

char* generate_package_key(json_t* index);
    - Generuje unikátní klíč balíčku ("name-version-build.tar.bz2") z polí name/version/build; vrací mallocovaný string nebo NULL.

void collect_packages(const char* root_path, json_t* packages, Pool *pool, Repo *repo);
    - Rekurzivně prochází adresář repo, načítá index.json, doplňuje defaultní pole (build_number, license atd.), vytváří Solvables (s name/EVR/arch), ukládá custom metadata do Repodata (mkdeps/source/extras/is_group/no_package) a parsuje depends; přidává do packages objektu pro repodata.json.

int generate_repodata(const char* repo_path, Pool *pool, Repo *repo);
    - Hlavní entry point: Vytváří repodata.json (s info/packages sekcemi), volá collect_packages a zapisuje výstup; volitelně integruje s libsolv (pool/repo); vrací 0 při úspěchu.

void parse_depends_to_solvable(Solvable *s, json_t *depends, Pool *pool);
    - Parsuje depends array (stringy jako "pkg >= 1.0") do Reldep Id (pool_rel2id s REL_* konstantami) a přidává do s->requires (solvable_add_deparray); skipuje invalidní položky.

json_t* get_custom_mkdeps(Repodata *data, Id p, Pool *pool);
    - Lookup "makedeps" string z Repodata, parsuje zpět do json_array (json_loads); vrací array (caller json_decref) nebo NULL.

const char* get_custom_source(Repodata *data, Id p, Pool *pool);
    - Lookup "download_url" string z Repodata; vrací URL nebo NULL (bez free).

json_t* get_custom_extras(Repodata *data, Id p, Pool *pool);
    - Lookup "extras" string z Repodata, parsuje do json_array; vrací array (caller json_decref) nebo NULL.

int get_custom_is_group(Repodata *data, Id p, Pool *pool);
    - Lookup "is_group" string ("true"/"false") z Repodata; vrací bool (1/0).

int get_custom_no_package(Repodata *data, Id p, Pool *pool);
    - Lookup "no_package" string ("true"/"false") z Repodata; vrací bool (1/0).

void internalize_repo(Repo *repo);
    - Volá repo_internalize pro indexaci repo (whatprovides/obsoletes); loguje info.

parser

Description
----
Source file: parser.c

This module provides functions for parsing a package repository in Conda-like format (index.json per package), recursive directory traversal, generating repodata.json, and integrating metadata into libsolv structures (Solvables and Repodata). It supports custom fields inspired by LFS/LLD (mkdeps for build-time dependencies, source for download URL, extras for patches/scripts, is_group/no_package for meta/virtual packages). Includes dependency parsing (depends array to SOLVABLE_REQUIRES) and error handling with logging.

Key functions
----
json_t* load_json(const char* filepath);
    - Loads JSON file (e.g., index.json) using jansson; returns root object or NULL on error (with log_error).

char* generate_package_key(json_t* index);
    - Generates unique package key ("name-version-build.tar.bz2") from name/version/build fields; returns malloc'd string or NULL.

void collect_packages(const char* root_path, json_t* packages, Pool *pool, Repo *repo);
    - Recursively traverses repo directory, loads index.json, adds default fields (build_number, license etc.), creates Solvables (with name/EVR/arch), stores custom metadata in Repodata (mkdeps/source/extras/is_group/no_package), and parses depends; adds to packages object for repodata.json.

int generate_repodata(const char* repo_path, Pool *pool, Repo *repo);
    - Main entry point: Creates repodata.json (with info/packages sections), calls collect_packages, and writes output; optionally integrates with libsolv (pool/repo); returns 0 on success.

void parse_depends_to_solvable(Solvable *s, json_t *depends, Pool *pool);
    - Parses depends array (strings like "pkg >= 1.0") into Reldep Id (pool_rel2id with REL_* constants) and adds to s->requires (solvable_add_deparray); skips invalid items.

json_t* get_custom_mkdeps(Repodata *data, Id p, Pool *pool);
    - Looks up "makedeps" string from Repodata, parses back to json_array (json_loads); returns array (caller json_decref) or NULL.

const char* get_custom_source(Repodata *data, Id p, Pool *pool);
    - Looks up "download_url" string from Repodata; returns URL or NULL (no free).

json_t* get_custom_extras(Repodata *data, Id p, Pool *pool);
    - Looks up "extras" string from Repodata, parses to json_array; returns array (caller json_decref) or NULL.

int get_custom_is_group(Repodata *data, Id p, Pool *pool);
    - Looks up "is_group" string ("true"/"false") from Repodata; returns bool (1/0).

int get_custom_no_package(Repodata *data, Id p, Pool *pool);
    - Looks up "no_package" string ("true"/"false") from Repodata; returns bool (1/0).

void internalize_repo(Repo *repo);
    - Calls repo_internalize to index repo (whatprovides/obsoletes); logs info.


Project integration
----
Used in main.c for repo initialization (generate_repodata("/tmp/test_repo", pool, repo)) and in solver.c for metadata loading
(get_custom_* for mkdeps recursion, parse_depends_to_solvable). Optional libsolv integration (pool/repo parameters)
allows standalone use (just repodata.json). Tested in test_parser.c (Check framework) with /tmp/test_repo; ~80% coverage for core functions.
