cmd_clean_cache
=============
(English below)

Popis
----
Zdrojový soubor: commands/cmd_clean_cache.c

Modul implementuje příkaz clean-cache, který maže dočasné soubory v cache
adresáři balíkového správce (/var/cache/balikar/downloads/ a extras/). Příkaz
podporuje dvě varianty:

    1. Vymazání cache konkrétního balíku (--pkg PKG_NAME):
       smaže pouze stažené archivy a extras pro daný balík.
    2. Vymazání celé cache (bez --pkg):
       smaže veškerý obsah downloads/ a extras/; vyžaduje potvrzení
       uživatelem (user_confirm), protože jde o destruktivní operaci.

Příkaz respektuje --dry-run: zobrazí co by bylo smazáno bez skutečné akce.


Klíčové funkce
----

static const char *get_cache_dir(void);
- Vrátí cestu ke kořenovému cache adresáři.
- Výchozí hodnota: /var/cache/balikar/downloads/
- Adresář extras/ je vždy na stejné úrovni jako downloads/.

int cmd_clean_cache_execute(CommandContext *ctx);
- Parsuje --pkg pro filtrování na konkrétní balík.
- Pokud --pkg: smaže pouze soubory odpovídající vzoru PKG_NAME* v downloads/ a extras/.
- Bez --pkg: user_confirm → smaže vše v downloads/ a extras/ rekurzivně.
- Respektuje --dry-run v obou větvích.
- Vypíše celkový počet smazaných souborů a uvolněné místo.
- Vrací 0 při úspěchu, 1 při selhání nebo odmítnutí potvrzení.

(žádný validátor – validate=NULL v command_registry.c, protože --pkg je volitelné)


Integrace v projektu
----
Nepotřebuje pool/repo ani žádný ze subsystémů (solver, downloader, builder, installer).
Pracuje přímo se souborovým systémem přes standardní C API (opendir/readdir/unlink/rmdir).
Registrace v command_registry.c: "clean-cache" → cmd_clean_cache_execute, validate=NULL.

cmd_clean_cache
=============

Description
----
Source file: commands/cmd_clean_cache.c

The module implements the clean-cache command, which deletes temporary files in the
package manager cache directory (/var/cache/balikar/downloads/ and extras/). The
command supports two variants:

    1. Clear cache for a specific package (--pkg PKG_NAME):
       deletes only downloaded archives and extras for that package.
    2. Clear complete cache (without --pkg):
       deletes all content of downloads/ and extras/; requires user confirmation
       (user_confirm) because it is a destructive operation.

The command respects --dry-run: shows what would be deleted without taking action.


Key functions
----

static const char *get_cache_dir(void);
- Returns the path to the root cache directory.
- Default value: /var/cache/balikar/downloads/
- The extras/ directory is always at the same level as downloads/.

int cmd_clean_cache_execute(CommandContext *ctx);
- Parses --pkg for filtering to a specific package.
- With --pkg: deletes only files matching the pattern PKG_NAME* in downloads/ and extras/.
- Without --pkg: user_confirm → deletes everything in downloads/ and extras/ recursively.
- Respects --dry-run in both branches.
- Prints total number of deleted files and freed disk space.
- Returns 0 on success, 1 on failure or confirmation refusal.

(no validator – validate=NULL in command_registry.c because --pkg is optional)


Project integration
----
Does not require pool/repo or any subsystem (solver, downloader, builder, installer).
Operates directly on the filesystem via standard C API (opendir/readdir/unlink/rmdir).
Registered in command_registry.c: "clean-cache" → cmd_clean_cache_execute,
validate=NULL.
