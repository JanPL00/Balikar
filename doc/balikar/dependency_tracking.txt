================================================================================
DEPENDENCY TRACKING & AUTOREMOVE - DOKUMENTACE
================================================================================

PŘEHLED
-------
Balikar automaticky sleduje důvod instalace každého balíčku a umožňuje
bezpečné odstraňování balíčků s detekcí osiřelých závislostí.

INSTALL_REASON
--------------
Každý nainstalovaný balíček má pole "install_reason" v databázi:

1. "manual" - balíček instalován přímo uživatelem
   - balikar install <pkg>
   - balikar install --local-package=<path>
   
2. "dependency" - balíček instalován automaticky jako závislost
   - Automaticky při instalaci jiného balíčku
   - Není explicitně požadován uživatelem

PŘÍKLAD DATABÁZE
----------------
/var/lib/balikar/installed.json:

    "bash-5.3": {

      "files": ["/usr/lib/libreadline.so", ...]

    "ncurses-6.5": {
      "name": "ncurses",
      "version": "6.5",
      "install_date": "2025-11-30T18:29:30Z",

      "files": ["/usr/lib/libncurses.so", ...]
    },

      "name": "glibc",

WORKFLOW REMOVE
---------------
Při odstranění balíčku (balikar remove):

1. KONTROLA REVERSE DEPENDENCIES
   - Najde všechny nainstalované balíčky, které potřebují odstraňovaný balíček
   - Pokud existují → varování a vyžádání potvrzení (default: n)
   
   Příklad:
   $ balikar remove glibc
   [WARN] Package 'glibc' is required by the following installed packages:
   [WARN]   - ncurses
   [WARN]   - readline
   [WARN]   - bash
   [WARN] Removing 'glibc' may break these packages.
   Continue with removal? [n]: 

2. ODSTRANĚNÍ BALÍČKU
   - Odstraní všechny soubory podle file manifestu
   - Aktualizuje installed.json (smaže záznam)

3. DETEKCE OSIŘELÝCH ZÁVISLOSTÍ
   - Po úspěšném odstranění analyzuje systém
   - Najde balíčky s install_reason="dependency", které už nikdo nepotřebuje
   - Zobrazí seznam osiřelých balíčků
   
   Příklad:
   $ balikar remove bash
   [INFO] Removed 162 files (0 failed)
   [INFO] Successfully erased package: bash
   [INFO]
   [INFO] The following packages were installed as dependencies and are no longer required:
   [INFO]   readline
   [INFO] Use 'balikar autoremove' to remove them.

AUTOREMOVE ALGORITMUS
---------------------

1. NAČTENÍ DATABÁZE
   - Načte installed.json z target root
   - Pro každý balíček přečte install_reason

2. IDENTIFIKACE KANDIDÁTŮ
   - Vybere všechny balíčky s install_reason="dependency"
   
3. KONTROLA REVERSE DEPENDENCIES
   - Pro každý kandidát:
     a) Najde jeho solvable v repository pool
     b) Iteruje přes všechny nainstalované balíčky
     c) Kontroluje, zda některý z nich má tento balíček v requires
     d) Pokud ANO → balíček NENÍ osiřelý (potřebují ho)
     e) Pokud NE → balíček JE osiřelý (nikdo ho nepotřebuje)

4. ZOBRAZENÍ A POTVRZENÍ
   - Vypíše seznam osiřelých balíčků
   - Vyžádá potvrzení od uživatele
   
5. ODSTRANĚNÍ
   - Iterativně odstraní všechny osiřelé balíčky
   - Po každém odstranění může vzniknout nový osiřelý balíček
   - Autoremove lze spustit opakovaně

PŘÍKLADY POUŽITÍ
----------------

1. ZÁKLADNÍ SCÉNÁŘ
   
   # Instalace bash (instaluje i závislosti)
   $ balikar install bash
   Transaction summary:
   Install: glibc-.noarch       (dependency)
   Install: ncurses-.noarch     (dependency)
   Install: readline-.noarch    (dependency)
   Install: bash-.noarch        (manual)
   
   # Odstranění bash
   $ balikar remove bash
   [INFO] Successfully erased package: bash
   [INFO] The following packages were installed as dependencies and are no longer required:
   [INFO]   readline
   [INFO] Use 'balikar autoremove' to remove them.
   
   # Autoremove readline
   $ balikar autoremove
   [INFO] Found 1 orphaned package(s):
   [INFO]   - readline
   Remove these packages? [y]: y
   [INFO] Removed 1 orphaned package(s)
   
   # Autoremove ncurses (osiřel po odstranění readline)
   $ balikar autoremove
   [INFO] Found 1 orphaned package(s):
   [INFO]   - ncurses
   Remove these packages? [y]: y
   [INFO] Removed 1 orphaned package(s)
   
   # Autoremove glibc (osiřel po odstranění ncurses)
   $ balikar autoremove
   [INFO] Found 1 orphaned package(s):
   [INFO]   - glibc
   Remove these packages? [y]: y
   [INFO] Removed 1 orphaned package(s)
   
   # Žádné další osiřelé balíčky
   $ balikar autoremove
   [INFO] No orphaned packages to remove.

2. OCHRANA PROTI ROZBITÍ SYSTÉMU
   
   # Pokus o odstranění glibc (potřebují ho všichni)
   $ balikar remove glibc
   [WARN] Package 'glibc' is required by the following installed packages:
   [WARN]   - ncurses
   [WARN]   - readline
   [WARN]   - bash
   [WARN] Removing 'glibc' may break these packages.
   Continue with removal? [n]: n
   [INFO] Removal cancelled.
   
   # Pokud uživatel potvrdí, odstranění proběhne (nebezpečné!)
   $ balikar remove glibc
   Continue with removal? [n]: y
   [INFO] Successfully erased package: glibc
   # POZOR: Systém je nyní rozbitý!

3. CHROOT PROSTŘEDÍ
   
   # Instalace do LFS
   $ balikar install bash --root=/mnt/lfs
   
   # Odstranění z LFS
   $ balikar remove bash --root=/mnt/lfs
   [INFO] The following packages were installed as dependencies and are no longer required:
   [INFO]   readline
   [INFO] Use 'balikar autoremove --root=<path>' to remove them.
   
   # Autoremove v LFS
   $ balikar autoremove --root=/mnt/lfs
   [INFO] Found 1 orphaned package(s):
   [INFO]   - readline
   Remove these packages? [y]: y

4. DRY-RUN AUTOREMOVE
   
   # Zjistit co by se odstranilo
   $ balikar autoremove --dry-run
   [INFO] Found 3 orphaned package(s):
   [INFO]   - readline
   [INFO]   - ncurses
   [INFO]   - glibc
   [INFO] DRY-RUN: Would remove 3 orphaned package(s)
   
   # Skutečné odstranění
   $ balikar autoremove
   Remove these packages? [y]: y

5. VÍCE MANUÁLNÍCH BALÍČKŮ
   
   # Instalace gcc a bash
   $ balikar install gcc
   $ balikar install bash
   
   # Oba sdílí glibc jako závislost
   # Po odstranění bash:
   $ balikar remove bash
   [INFO] The following packages were installed as dependencies and are no longer required:
   [INFO]   readline
   
   # glibc NENÍ osiřelý (gcc ho stále potřebuje)
   $ balikar autoremove
   [INFO] Found 1 orphaned package(s):
   [INFO]   - readline
   # Pouze readline je osiřelý

IMPLEMENTAČNÍ DETAILY
---------------------

FUNKCE find_reverse_dependencies()
  - Vstup: pkg_name, chroot_path, pool, repo
  - Výstup: JSON array názvů balíčků, které závisí na pkg_name
  
  Algoritmus:
  1. Najde solvable ID pro pkg_name v pool
  2. Načte installed.json z chroot
  3. Pro každý nainstalovaný balíček:
     - Najde jeho solvable v pool
     - Iteruje přes jeho requires
     - Pokud requires může uspokojit pkg_name → přidá do výsledku
  4. Vrátí JSON array s reverse dependencies

FUNKCE find_orphaned_packages()
  - Vstup: chroot_path, pool, repo
  - Výstup: JSON array názvů osiřelých balíčků
  
  Algoritmus:
  1. Načte installed.json z chroot
  2. Pro každý balíček s install_reason="dependency":
     - Zavolá find_reverse_dependencies()
     - Pokud je výsledek prázdný → balíček je osiřelý
  3. Vrátí JSON array s osiřelými balíčky

FUNKCE erase_package_with_checks()
  - Vstup: pkg_name, chroot_path, pool, repo, show_orphans
  - Výstup: 0 (úspěch), -1 (chyba nebo zrušeno)
  
  Workflow:
  1. Pokud pool && repo:
     - Zavolá find_reverse_dependencies()
     - Pokud najde → zobrazí varování a vyžádá potvrzení
     - Default odpověď: n (bezpečnější)
  2. Zavolá erase_package() (skutečné odstranění)
  3. Pokud show_orphans && pool && repo:
     - Zavolá find_orphaned_packages()
     - Zobrazí seznam osiřelých balíčků
     - Navrhne 'balikar autoremove'
  4. Vrátí výsledek

FUNKCE autoremove_packages()
  - Vstup: chroot_path, pool, repo, dry_run
  - Výstup: počet odstraněných balíčků nebo -1 (chyba)
  
  Workflow:
  1. Zavolá find_orphaned_packages()
  2. Pokud žádné osiřelé → vrátí 0
  3. Zobrazí seznam osiřelých balíčků
  4. Pokud dry_run → vrátí 0
  5. Vyžádá potvrzení (default: y)
  6. Pro každý osiřelý balíček:
     - Zavolá erase_package()
  7. Vrátí počet odstraněných balíčků

OMEZENÍ A POZNÁMKY
------------------

1. ITERATIVNÍ AUTOREMOVE
   - Po odstranění balíčku mohou vzniknout nové osiřelé balíčky
   - Autoremove odstraní pouze aktuálně osiřelé
   - Pro kompletní vyčištění je třeba spustit autoremove opakovaně
   
   Příklad:
   bash → readline → ncurses → glibc
   
   $ balikar remove bash
   $ balikar autoremove  # Odstraní readline
   $ balikar autoremove  # Odstraní ncurses
   $ balikar autoremove  # Odstraní glibc

2. POOL A REPO REQUIREMENT
   - find_reverse_dependencies() vyžaduje pool a repo
   - Používá libsolv pro kontrolu dependencies
   - Bez pool/repo nelze detekovat reverse dependencies

3. INSTALL_REASON PERSISTENCE
   - install_reason je uložen v installed.json
   - Přežívá reboot a reinstalaci balikaru
   - Migrace starých instalací: chybí install_reason → považuje se za "manual"

4. BEZPEČNOSTNÍ ASPEKTY
   - Varování při odstranění s reverse deps (default: n)
   - Potvrzení před autoremove (default: y)
   - Žádné --force flag pro přeskočení kontrol
   - Uživatel má plnou kontrolu

MIGRACE EXISTUJÍCÍCH INSTALACÍ
------------------------------
Pokud máte starší installed.json bez install_reason:

1. Automatická migrace:
   - Balíčky bez install_reason se považují za "manual"
   - Autoremove je nepokládá za kandidáty na odstranění

2. Manuální úprava (pokud víte co jsou závislosti):
   - Edituj /var/lib/balikar/installed.json
   - Přidej "install_reason": "dependency" ke všem závislostem

DEBUGGING
---------

# Zobrazit install_reason všech balíčků
$ cat /var/lib/balikar/installed.json | grep -E '"name"|"install_reason"'

# Zkontrolovat reverse dependencies manuálně
$ balikar remove <pkg>  # Zobrazí varování s reverse deps

# Dry-run autoremove pro zjištění osiřelých
$ balikar autoremove --dry-run

# Debug mode pro detailní output
$ balikar -d remove <pkg>
$ balikar -d autoremove

BEST PRACTICES
--------------

1. Po odstranění balíčku vždy spusť autoremove
2. Používej --dry-run pro zjištění co se odstraní
3. V produkčním prostředí (/) buď opatrný
4. V chroot prostředí můžeš experimentovat bezpečně
5. Pravidelně čisti osiřelé balíčky pro úsporu místa
